# 개발 학습 자료

## 목차

이 자료는 Ubuntu 기본 조작부터 Git, ROS 2, 문서 작성, C++ 컴파일까지 주제별로 정리했습니다.

## 권장 학습 순서

1. [Linux/Ubuntu 기본 명령어](linux_ubuntu.md) — 경로 이동, 폴더·파일 생성, 편집, 이동과 이름 변경
2. [Git/GitHub](git_github.md) — Git 기본 흐름, SSH 연결, 최초 업로드와 보안 문제 해결
3. [Markdown](markdown.md) — Markdown 참고 링크
4. [MkDocs](mkdocs.md) — 문서 사이트, 가상 환경, TIL 운영 규칙
5. [C++ g++ 컴파일](cpp_gpp.md) — 컴파일 옵션과 실행
6. [ROS 2 Humble 및 실습](ros2_humble.md) — 설치 확인, 워크스페이스, 실습, 통신 및 문제 해결
7. [참고자료 및 학습 링크](references.md) — 원본 자료에서 제공한 링크

## 공통 기준

- 셸에서 경로 이동, 디렉터리·파일 생성, 편집, 이동은 [Linux/Ubuntu 문서](linux_ubuntu.md)를 기준으로 봅니다.
- 저장소 상태 확인, 스테이징, 커밋, 원격 저장소 작업은 [Git/GitHub 문서](git_github.md)를 기준으로 봅니다.
- ROS 2 빌드 산출물(`build/`, `install/`, `log/`)을 Git에 포함하지 않도록 주의합니다.
