## 개요

`g++`로 C++ 소스 파일을 컴파일하고 실행 파일을 만드는 방법을 정리합니다. 아래 예시는 Linux/macOS 기준이며 Ubuntu에서는 `./main`으로 실행합니다.

## 기본 명령

```bash
g++ main.cpp -o main
./main
```

학습 시 권장하는 기본 형태는 경고를 켜고 C++17 표준을 지정합니다.

```bash
g++ -Wall -std=c++17 main.cpp -o main
./main
```

## 컴파일 옵션 상세 설명

| 요소 | 설명 |
|---|---|
| `g++` | C++ 컴파일러 |
| `-Wall` | 주요 컴파일 경고 활성화 |
| `-std=c++17` | C++17 표준 사용 |
| `main.cpp` | 입력 소스 파일 |
| `-o main` | 생성할 실행 파일 이름 지정 |

### `-Wall`

```bash
g++ -Wall main.cpp -o main
```

잠재적 문제를 알려주는 주요 경고를 활성화합니다. 예를 들어 사용하지 않는 변수나 일부 문법 문제를 알려줄 수 있습니다. 경고가 없다고 코드에 문제가 전혀 없다는 뜻은 아닙니다.

### `-std=c++17`

```bash
g++ -std=c++17 main.cpp -o main
```

C++11, C++14, C++17, C++20, C++23 등 중 사용할 언어 표준을 지정합니다.

### 자주 쓰는 조합

```bash
g++ main.cpp -o main
g++ -Wall main.cpp -o main
g++ -std=c++17 main.cpp -o main
g++ -Wall -std=c++17 main.cpp -o main
```

## 실습 및 실행 흐름

컴파일과 실행을 한 줄로 이어서 실행할 수 있습니다.

```bash
g++ -Wall -std=c++17 main.cpp -o main && ./main
```

`&&`는 앞 명령이 성공했을 때 다음 명령을 실행합니다. 따라서 컴파일 성공 후 실행합니다.

```bash
# 1. 컴파일
g++ -Wall -std=c++17 main.cpp -o main

# 2. 실행
./main
```

Windows에서는 실행 파일을 보통 `main.exe`로 만들고 실행합니다.

```bash
g++ -Wall -std=c++17 main.cpp -o main.exe
main.exe
```

명령 구조:

```text
g++
├── -Wall          컴파일 경고 활성화
├── -std=c++17     C++17 표준 사용
├── main.cpp       입력 소스 파일
└── -o main        출력 실행 파일 이름
```

## 체크리스트

- [ ] 컴파일할 소스 파일 이름이 맞는지 확인했다.
- [ ] 필요한 표준 버전(`-std=c++17`)을 지정했다.
- [ ] 경고를 확인하기 위해 `-Wall`을 사용했다.
- [ ] 컴파일 성공 후 실행 파일을 실행했다.
