# Tilt 단독 구동 방향 및 기본 정지 시험

- 시험일: 2026-10-06
- 대상: Tilt ID 12
- 방향 기준: 카메라 뒤에서 정면을 바라보는 방향
- 원본 로그: [commission.log](commission.log)
- Pan: 토크 비활성화 유지

## 확인 결과

| 항목 | 결과 |
|---|---|
| 명시적 STOP | HOLDING 복귀 및 토크 유지 |
| ARM 대기 시간 초과 | HOLDING 복귀 |
| ARM 만료 후 JOG | ERR ARM_REQUIRED로 거부 |
| JOG - | 실제 위쪽 회전, 이후 위치 4068~4069 |
| JOG + | 실제 아래쪽 회전, 이후 위치 4073~4074 |
| 각 JOG 시간 초과 | JOG_TIMEOUT 이후 STOPPED HOLDING |
| 정지 후 상태 | 출력 속도 0, 토크 유지 |
| 시험 종료 | SUPPORTED_OFF 이후 TORQUE_OFF_CONFIRMED |

담당자가 두 JOG의 실제 회전 방향을 확인했다.
구동 및 정지 후 지지대는 카메라에 닿지 않았으며,
정지 후 육안으로 처짐이나 진동이 관찰되지 않았다.

DRIFT와 PEAK는 최초 HOLD 위치를 기준으로 하며,
의도적으로 명령한 이동도 포함한다.

## 검증 범위

시험한 중립 부근에서 방향 및 기본 정지 동작을 검증했다.
위치 경계 정지, 실제 정지 지연, 모터 버스 통신 단절,
피드백 실패 및 두 축 동시 구동은 아직 검증하지 않았다.
